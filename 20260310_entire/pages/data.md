# Entire: データ構造

```
entire/checkpoints/v1 ブランチ

<id[:2]>/<id[2:]>/
├── metadata.json       # CheckpointSummary
│     CheckpointID, Branch, FilesTouched
│     sessions: [ CommittedMetadata ]
│       SessionID, Agent, TurnID
│       summary:
│         intent / outcome / friction
│         open_items / learnings
│       initial_attribution:
│         agent_lines / human_added
│         agent_percentage
│       token_usage:
│         input / output / cache_read
├── 1/
│   ├── metadata.json   # CommittedMetadata
│   ├── full.jsonl      # 会話全文 + Tool Calls
│   └── prompt.txt      # ユーザープロンプト
└── 2/ ...
```

::right::

<div class="ml-4 mt-8 text-sm">

**保存されるもの**

| カテゴリ | 内容 |
|---|---|
| 会話 | プロンプト・レスポンス全文 |
| Tool Calls | 引数・実行結果 |
| File Diff | 変更差分 |
| 帰属 | AI/Human 行数・割合 |
| 要約 | intent / outcome（AI生成） |
| 統計 | token使用量・ステップ数 |

<br/>

**保存先**: `entire/checkpoints/v1` ブランチ（固定）

**タイミング**: `git commit` のたびに git-hook で自動記録

</div>

```json
{
  "version": "0.1.0",

    {
      "path": "src/utils/parser.ts",
      "conversations": [
        {
          "url": "https://api.cursor.com/v1/conversations/12345",
          "contributor": {
            "type": "ai",
            "model_id": "anthropic/claude-opus-4-5"
          },
          "ranges": [
            { "start_line": 42, "end_line": 67 }
          ]
        }
      ]
    }
  ],
  "metadata": { "dev.cursor": { "workspace_id": "ws-abc" } }
}
```

::right::

<div class="ml-4 text-sm">

**保存されるもの**

| フィールド | 内容 |
|---|---|
| `vcs.revision` | git commit SHA |
| `tool` | エージェント名・バージョン |
| `files[].path` | 変更ファイルパス |
| `conversations[].url` | 会話へのURL（本文は外部） |
| `contributor.type` | ai / human / mixed |
| `contributor.model_id` | 使用モデル識別子 |
| `ranges` | 行単位の帰属範囲 |

<br/>

**保存先**: 実装定義（ファイル・DB・git notes 等）

**会話本文**: URLで外部参照 → PII等をトレース外に隔離

</div>

# Entire vs Agent Trace: 比較

| | Entire Checkpoints | Agent Trace |
|---|---|---|
| **記録単位** | Checkpoint（git commit紐付け） | Trace Record（commit以下も可） |
| **会話本文** | gitブランチに直接保存 | URLで外部参照（保存先は実装定義） |
| **Tool Calls** | 引数・結果を全保存 | 対象外（仕様に含まれない） |
| **帰属粒度** | ファイル単位（AI% / Human行数） | 行範囲単位・複数モデル対応 |
| **AI要約** | intent / outcome を自動生成 | 対象外 |
| **センシティブ情報** | ベストエフォートでマスク | URLリンクにより本体をトレース外に置く |
| **ストレージ** | `entire/checkpoints/v1` 固定 | 実装定義 |
| **標準化** | Entire 独自仕様 | オープン仕様（Cursor / Cognition 等参加） |

<br/>

> **Entire**: Trajectoryを丸ごとgitに残す「記録重視」のアプローチ  
> **Agent Trace**: 最小限の帰属情報＋URLリンクの「相互運用重視」のアプローチ
